# 04 · 机会点与策略

## 1. 总体判断

| 战场 | 态势 | 我们的定位 |
|---|---|---|
| T1 自动分 | 饱和（官方盖章"满分是设计预期"） | 快速拿满分（入场券），不恋战 |
| T1 methods 报告 | 评审单独打分，真正的分差所在 | 重仓投入 |
| **T2 药物重定位** | **官方明示的价值洼地**（参与不足、配额反升、公开喊话） | **主战场** |
| 🌟 创新/社区奖 | 独立于名次，评委裁量 | 第三条路径，与 T2 复用素材 |

## 2. T1 打法

**管线目标**：全自动、可复现、有消融实验。Exomiser 起基线 + 自建 comp-het 过滤链。

**提交策略——把 6 次配额当"神谕"用**：
- 每次提交即时返回 full match（第几名）/ partial（第几名）/ no match
- 第 1 次尽早提交（哪怕保守版）：校验格式 + 拿到首次反馈，零风险试水
- **正确姿势**：comp-het 对**写同一行**（chrom_1..alt_2 两变异齐全）才计 full match 100 分；拆成两行每行最多拿 partial 半分

**methods 报告要素**（对照评审口味：科学严谨 + 理解深度）：
- ACMG/AMP 分级路径、comp-het 反式证据（read-backed / 统计定相）
- 基因-表型匹配（HPO 相似度）、AF 过滤逻辑（gnomAD/TOPMed）、call 质量（深度/GQ/allele balance）
- Secondary findings 的临床处理建议（体现"以患者为中心"）
- LLM 使用披露行（硬性要求）

## 3. T2 打法（精力按评审权重分配）

- **Scientific Rigor 35%**：机制链条完整——变异 → BUBR1 LOF → SAC 减弱 → 非整倍体风暴 → 表型 + 癌易感；**证据分级表**（每条证据标注来源类型与强度）；方法可复现（代码 + 数据库版本号）
- **Potential Impact 25%**：落到患儿的现实获益——癌症预防（~75% 发生率是最大可干预风险）、监测优化、症状缓解；候选药物给出**线虫（C. elegans）可检验的预测**，直接衔接 MVA Society 自己资助的筛选体系
- **Innovation 25%**："LOF 肿瘤抑制蛋白不可直接成药 → 绕路"这一框架本身就是创新叙事；多角度组合：LINCS L1000 签名反转 + 通路补偿 + 非整倍体细胞清除
- **Scalability 15%**：把方案抽象成 **"N-of-1 罕见病重定位工作流"**（任意基因/表型输入 → 机制刻画 → 候选药物排序）——我们的管线即产品，叙事一鱼两吃

**时间线内动作**：3 次配额、只看最新一次 → W6 先提交 v1 占坑，W7 终版覆盖，留 1 次余量防意外。

**视频**：3 分钟，故事线"从患儿的基因组到一个可检验的药物假设"，先脚本后录制。

## 4. 🌟 创新奖角度（以患者为中心，独立评奖）

- **面向家庭的"结果解释器"**：把 comp-het 诊断 + 药物假设翻译成家长能读懂的通俗语言（HTML/交互页）
- **MVA 监测日历工具**：按已发表监测建议自动生成筛查时间表（Wilms 瘤超声等）——直接服务家庭日常
- **社区能见度**：公开教程、在讨论区高质量答疑（社区奖看"community impact"）
- 以上均作为 T2 报告的 "Patient-facing deliverables" 章节，与主提交复用素材
