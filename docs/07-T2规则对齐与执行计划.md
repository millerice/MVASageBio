## 6. T2 架构与存储约定（2026-09-08 搭建完成）

**核心设计**：机制链机器可读（`research/mechanism_chain.json`，nodes 带 ev_refs/granularity/conflict_note），台账与报告从它生成/校验——「每条 claim 可溯源」由代码强制（M5 审查门的自动化部分），不靠纪律。

```
src/track2_repurposing/
├── ledger.py            # 台账 CLI：lint（schema 关卡）/ stats / show / grep
├── validate_chain.py    # 机制链×台账交叉审计（R1–R6）；--dot 出机制图
├── build_drug_pool.py   # M2 药池（骨架，--dry-run 看数据源计划）
├── score_candidates.py  # M2 评分（骨架）
└── README.md            # 模块文档（含运行命令）
research/mechanism_chain.json   # M1 机制链本体（12 nodes / 13 edges，granularity: public 10 / report 2）
reports/JiuTian-Bio_track2_report.md   # 报告骨架（11 问结构 + EV 占位符）
```

**两道自动化关卡**（M5 放行前置）：`ledger.py lint` ✓（57 条全过）→ `validate_chain.py` ✓（ev_refs 全溯源；conflict 引用必须带注记；hypothesis 必须带反面注记——首跑即抓出 2 处真问题并已修复）。

**存储约定**：
- T2 主体**不依赖原始测序数据**——本机磁盘（~137GB 可用）放不下 79GB FASTQ + 比对中间件，全部走「文献 + 台账 + 公开药物数据库」
- 用户接入 SSD 后的可选增强（任务 #9 解冻条件）：FASTQ → 比对 → read-backed 定相（直接验证 comp-het trans）、全基因组注释佐证；数据落 `/Volumes/<SSD>/mva/`，仓库只留指针与结论级产物
- 公开 repo 口径：基因/结构域级；`granularity=report` 的内容（HGVS/残基）只进提交报告
