## 3. Track 1 变异预测（自动评分）

任务：从 WGS + 表型找回致病变异。**答案 key 为一对临床验证的复合杂合（compound-heterozygous）变异**（evaluation.py docstring 原文确认，N-of-1）。

**提交三件套（全部必填）**：① 预测 CSV；② 方法报告 PDF/MD（用官方最新模板 `methods_description_form.xlsx`，8/28 版新增 LLM 使用声明题）；③ GitHub URL（赛期可私有，**评审时必须公开**）。

**CSV 格式**（官方模板原样）：

```csv
proband_id,chrom_1,pos_1,ref_1,alt_1,chrom_2,pos_2,ref_2,alt_2,epcr,finding_type,notes
PROBAND01,chr1,100000,A,T,chr1,200000,G,C,0.90,primary,
PROBAND01,chr7,300000,C,T,,,,,0.30,secondary,Incidental finding unrelated to primary phenotype
```

- ≤10 行；**comp-het 对写同一行**（chrom_2…alt_2 填第二个变异）；epcr ∈ (0,1]；finding_type = `primary`/`secondary`（secondary 不影响自动分）；坐标 GRCh38
- 文件名带用户名+模型名，如 `millerkai_exomiser-v1.csv`

**评分算法**（源码级）：

- 行按 epcr 降序排列后逐行比对；**整行的变异 frozenset == 答案对**才算 full match
- Rank points 档位：第 1 名 **100**；≤3 名 50；≤5 名 25；≤10 名 10
- 只命中 comp-het 两变异之一 → 对应档位**半分**
- F-max：变异级别，跨全部唯一 epcr 阈值扫描取最优
- **每次提交即时返回 full / partial（第几名命中）/ no match 反馈** → 6 次配额相当于 6 次可校准的"神谕"查询
- 配额：**每人 6 次**，最高分入榜；团队成员各有独立配额，但须统一队名；榜单排序 rank_points ↓ → f_max ↓ → 提交更早者优先

**关键认知**：官方 FAQ 明确 T1 是"基础赛道"，满分是设计预期；**方法报告由评审组单独评**——两份满分卷的差距在报告里。

## 4. Track 2 药物重定位（专家评审）

任务：基于 T1 基因/变异机制，提出**已上市药物**（market-approved）重定位方案。

**提交物**：① 报告 PDF/MD——**必须包含变异机制刻画**（LOF/GOF、被破坏的通路、下游生物学后果）作为重定位理由的根基；② GitHub URL；③ 3 分钟 pitch 视频（YouTube/Vimeo 链接，必填）；④ Notes for judges（可选）。

**配额**：**3 次**（8/28 从 1 次上调）；**评委只评审最新一次提交**；团队指定一人提交。

**评审标准**：

| 标准 | 权重 | 备题方向 |
|---|---|---|
| Scientific Rigor | 35% | 机制链条完整、证据分级、方法可复现 |
| Potential Impact | 25% | 对患儿/家庭的现实获益 |
| Innovation | 25% | 角度新颖、假设可检验 |
| Scalability | 15% | 能否推广到其他罕见病 N-of-1 |

评委 = 研究者 + 临床医生 + 患者倡导者；预录视频、无 live Q&A；评审约 2–3 个月。

## 5. LLM 使用合规（讨论 #2，Sage 首席隐私合规官裁决）

判定标准：服务是 **Processor（工具）还是 Recipient（数据接收方）**。

- ✅ 允许：仅为向你返回结果而处理数据、不取得数据权利、不用于自身目的（合规配置下的商业 LLM API、云端注释服务等）
- ❌ 禁止：服务商有权使用/保留/学习数据

两个必要条件：① 输入输出均不用于训练、服务商不取得任何权利；② 留存限时限用途（零留存非必需，短周期滥用监控日志可接受）。

两个坑（官方原话）：a) 关闭训练并不总是彻底——**反馈/点评分过的内容可能仍被使用，不要给输出点评分**；b) **credits/grant 计划可能附带覆盖账户默认的条款**，要读 credits 条款而不是默认账户设置。

**方法报告中必须记录一行**，官方示例：`"Anthropic API, Claude Sonnet, Commercial terms, no training on customer content"`。
