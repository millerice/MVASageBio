**精选 4 而非 5 的决策**：L2 与 L3 各有同轴第二药（sirolimus / HCQ），占两个名额不如
保 4 条相互独立的机制轴（蛋白稳态 / mTORC1 / 代谢-系统应激 / 非整倍体清除）——
轴多样性对评审的 Innovation/Scalability 叙事更有力，且每个假设可独立证伪。

## 3. 主候选三件套

### #1 Niacinamide（烟酰胺）— L1 蛋白稳态轴【首选】

- **机制匹配**：唯一直接作用于机制链核心节点 N5（BUBR1 蛋白不足）的候选。SIRT2–NAD+
  轴控制 BubR1 丰度：SIRT2 过表达或 NAD+ 前体（NMN）体内抬升 BubR1（原文点名 MVA，
  EV-0066）；基因层抬升 BubR1 方向具保护性（EV-0067）；错义致病机制=蛋白失稳而非催化
  丧失（EV-0044/0045）→ 抬升**残余突变蛋白丰度**是机制上自洽的干预方向。
- **Hypothesis**：已上市 NAD+ 前体 niacinamide 提高细胞内 NAD+/SIRT2 活性 → 残余
  missense 等位来源的 BUBR1 蛋白丰度抬升 → 向 ~13% 分离保真阈值方向改善（对照 ~6%
  大量错误分离，EV-0046），预期最可能获益域为蛋白稳态依赖性表型（早衰/肌萎缩成分），
  染色体分离保真度的改善为更远端且更弱的预期。
- **可检验预测**：
  1. 线虫（衔接 EV-0023 平台）：NAD+ 前体暴露后 SAC 弱化线虫的 BUBR1 正交蛋白丰度
     （报告读出：正交基因融合蛋白水平，不用 SIRT2 生化读出——线虫无干净 SIRT2 正交，
     sir-2.1 为 SIRT1 样，见 §5 待钉死）。
  2. 临床观察性（若进入探索）：患者淋巴细胞 BUBR1 蛋白丰度作为药效学生物标志物，
     干预前后自身对照。
- **反面证据/平移缺口（必须明示）**：① NMN 证据来自 BubR1 不足衰老小鼠，非 MVA
  missense 突变体（EV-0066 counter）；② ONTRAC RCT（EV-0070，500 mg BID×12mo，NMSC
  率 −23%）终点是皮肤癌预防、人群为成人——只作「已上市 NAD+ 前体人体 RCT 获益先例 +
  剂量参照」，不外推 MVA 癌谱；③ 抬升的是突变蛋白，其功能挽救程度未知（可能只救蛋白量
  不救功能，或救两者——线虫/细胞可分辨）。
- **上市状态**：us_approved（EV-0069；FDA 记录 USP 名 niacinamide，含儿科注射复合维生素
  剂型）。

### #2 Everolimus — L2 mTORC1-肌萎缩轴

- **机制匹配**：N11 早衰-肌萎缩（BubR1 不足→mTORC1 过激活相关肌萎缩、p19Arf 衰老介导
  组织退化，小鼠证据，EV-0057）。
- **Hypothesis**：mTORC1 抑制缓解 MVA 早衰表型中的肌萎缩/组织退化成分（**不触及**
  染色体分离核心缺陷——定位为症状域对症研究假设）。
- **可检验预测**：线虫 TORC1 操作（daf-15/Raptor，EV-0074）改善 SAC 弱化模型的肌肉
  功能/衰老读出；临床观察性终点=瘦体重/肌力而非非整倍体率。
- **反面证据（负担最重）**：① 儿童慢性免疫抑制（感染/口炎，EXIST-1 5% 因 AE 退出，
  EV-0071）；② **生长抑制 vs FTT 的直接矛盾**——生长衰竭患儿的 mTOR 抑制需极端谨慎，
  儿科移植文献有 sirolimus 生长损害记录（PMID M3 钉死，见 §5）；③ TSC 有直接 mTOR
  过激活遗传学依据，MVA 侧仅有小鼠肌萎缩模型（EV-0057 counter）。
- **上市状态**：us_approved（EV-0069）；儿科先例=TSC-SEGA III 期 RCT+长期扩展（EV-0071）。

### #3 Metformin — L4 代谢-系统应激轴

- **机制匹配**：N13 系统性/慢性免疫应激（EV-0061）+ 非整倍体细胞的代谢适应依赖。
  已上市 AMPK/能量状态调节剂；在染色体三体（DS）模型逆转线粒体功能障碍（EV-0072）、
  AMPK 激活跨物种保护（线虫→细胞→小鼠，EV-0073）。
- **Hypothesis**：MVA 嵌合非整倍体带来的细胞自主代谢应激与系统炎症成分可被药理学
  能量状态调节所修饰——目标域为**症状负担/应激耐受**（生长环境优化），非非整倍体率本身。
- **方向张力（诚实处理，报告必写）**：能量应激轴在文献中呈场景依赖的双向——
  Tang 2011（EV-0063）：AICAR 选择性**抑制非整倍体细胞增殖**（肿瘤预防场景）；
  DS 模型（EV-0072/0073）：AMPK 激活**保护三体细胞功能**（发育/组织功能场景）。
  两者的表面冲突按场景（恶变前清除 vs 发育中功能支持）与层面（细胞自主 vs 机体）
  解释；metformin 候选明确定位后者，报告不混用两方向。
- **可检验预测**：线虫（DS 三体模型先例 EV-0073 → MVA SAC 弱化模型）：metformin/aak-2
  轴改善应激耐受读出；临床观察性：炎症/代谢生物标志物谱变化。
- **反面证据**：零 MVA 模型直接证据；DS 终点（神经保护）≠ MVA 终点；FTT 儿童中剂量/
  获益未建立（儿科 metformin 安全性经验来自 PCOS/胰岛素抵抗人群）。
- **上市状态**：us_approved（EV-0069）。

### #4 Chloroquine — L3 非整倍体清除轴

- **机制匹配**：N7/N10——**唯一有 MVA 模型直接证据的候选**：Tang 2011 中 AICAR/17-AAG/
  氯喹选择性抗非整倍体细胞增殖，且在 BubR1^H/H（MVA 模型）MEF 验证（EV-0063）。
- **Hypothesis**：自噬抑制选择性地限制高非整倍体负荷细胞的增殖适应性 → 降低恶性转化
  风险（**肿瘤预防场景**；与 #3 的功能支持场景方向相反，报告中分列不混用）。
- **可检验预测**：患者来源细胞（高 vs 低非整倍体亚群）对氯喹的增殖敏感性差异；
  器官水平：现有儿科队列零 MVA 干预试验（EV-0059）→ 任何探索均为 first-in-disease。
- **反面证据**：① 儿科长期使用=视网膜毒性（HCQ 较低，见备选）；② Tang 证据为细胞/
  MEF 层，无体内肿瘤预防数据（EV-0063 counter）；③ 线虫方法学警示：氯喹在线虫中
  并非可靠的自噬抑制剂（读出需改用溶酶体功能而非 LC3 flux——引用 M3 钉死，§5）；
  ④ 免疫抑制负担。
- **上市状态**：us_approved（EV-0069）。

## 4. 同轴备选与排除记录（报告「为什么不是它」素材）

| 药 | 处置 | 理由 |
|---|---|---|
| Sirolimus | 备选（L2） | 与 everolimus 同轴；儿科移植生长损害反面证据更重（M3 钉 PMID）；everolimus 有 TSC-SEGA 儿科 RCT 先例故为轴内首选 |
| Hydroxychloroquine | 备选（L3） | 氯喹的耐受性优化衍生物（视网膜毒性较低）但零 MVA 模型数据；轴内首选保留有直接证据的 CQ |
| Pioglitazone | 考虑未选（L4） | DS 细胞线粒体改善证据（EV-0075）但儿科长期安全性/黑框警示；metformin 同轴儿科证据更充分 |
| NMN | 排除 | 非批准药（膳食补充剂身份，EV-0069）——机制证据源但不可提名 |
| Tanespimycin (17-AAG) | 排除 | HSP90 抑制剂零 FDA 批准；且机制方向双重不利（HSP90 折叠支持为 BUBR1 所需，抑制方向反，EV-0065） |
| AICAR | 排除 | 无 FDA 批准（EV-0069）；metformin 为其已上市同类方向入口 |
