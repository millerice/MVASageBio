04 · 关键情报

五个改变打法的发现

  1. 答案是一对复合杂合（comp-het）变异。官方评分源码 docstring 明说 "clinically validated compound-heterozygous answer key"。两个变异必须写在 CSV 同一行才计满分，只中一个拿半分——T1 管线按隐性遗传设计。EV-0001
  2. T1 满分是官方设计预期。官方 FAQ 与 9/1 公告：T1 是"基础赛道"，"两份满分卷可以很不同"，methods 报告与自动分同等重要。拿满分只是入场券。EV-0014
  3. T1 每次提交即时返回命中反馈。full / partial（第几名命中）/ no match——6 次配额等于 6 次可校准的"神谕"查询，尽早试水，风险极低。EV-0002/0004
  4. LLM 合规已有官方裁决。Sage 首席隐私合规官逐条回复：用 Claude 等商业 API 完全允许，条件是 Processor 配置（不训练、限时留存）+ methods 披露一行 + 不给输出点评分。我们可以放心全程 AI 辅助。EV-0009
  5. 头号嫌疑基因：BUB1B = MVA 1 型（注意：不是 2 型——2 型是 CEP57）。与 comp-het 隐性答案结构吻合；BUB1B 位于 chr15，数据到手先查。这是置信度 0.6 的待验证假设。EV-0017 / EV-0024

05 · 战略

三线作战，精力按评审权重分配

主线 T2：机制链条 = 变异 → BUBR1 功能缺失 → 纺锤体检查点失效 → 非整倍体风暴 → 表型 + 约 75% 癌症风险。核心难题即卖点：功能缺失的肿瘤抑制蛋白无法直接给药激活，必须绕路——这本身就是 Innovation 叙事。

评审标准权重我们的对策
Scientific Rigor35%每条结论 EV 编号可溯源 + 主动列反面证据 + 代码可复现
Potential Impact25%落到患儿现实获益（癌症预防 / 监测优化），给出 MVA Society 线虫筛选体系可检验的预测
Innovation25%LOF 绕路框架 + LINCS L1000 签名反转 + 多角度组合
Scalability15%抽象成「N-of-1 罕见病重定位工作流」——管线即产品

副线 T1（快速满分，不恋战）：Exomiser 基线 + comp-het 过滤链 + 本地评分器（官方逻辑复刻）先验证再提交；满分后重仓 methods 报告（ACMG 分级、反式证据、HPO 匹配、次要发现的临床建议）。

第三路径 · 创新奖：家庭版"结果解释器"（把诊断和药物假设翻译成家长能懂的话）、MVA 监测日历工具——素材与 T2 报告复用。
