## 三、五个改变打法的发现

1. **答案是一对复合杂合（comp-het）变异**——官方评分源码 docstring 明说 "clinically validated compound-heterozygous answer key"。两个变异**必须写在 CSV 同一行**才计满分，只中一个拿半分 → T1 管线按隐性遗传设计
2. **T1 满分是官方设计预期**——官方 FAQ 与 9/1 公告：T1 是"基础赛道"，"两份满分卷可以很不同"，**methods 报告与自动分同等重要** → 拿满分只是入场券，报告才是分差
3. **T2 是明牌洼地**——官方主动把 T2 配额从 1 次加到 3 次，并在公告里喊话"T2 是最大未满足需求，把你们打 T1 的劲头拿来" → 主战场
4. **LLM 合规已有官方裁决**（Sage 首席隐私合规官逐条回复）：用 Claude 等商业 API 完全允许，条件是 Processor 配置（不训练、限时留存）+ methods 里披露一行 + 不给输出点评分 → 我们可以放心全程 AI 辅助
5. **头号嫌疑基因：BUB1B = MVA 1 型**（注意：不是 2 型，2 型是 CEP57）——与 comp-het 隐性答案结构吻合，BUB1B 位于 chr15，数据到手先查（EV-0024，置信度 0.6 的待验证假设）

## 四、战略：三线作战

**主线 · T2（精力大头）**：机制链条 = 变异 → BUBR1 功能缺失 → 纺锤体检查点失效 → 非整倍体风暴 → 表型 + ~75% 癌症风险。核心难题与卖点：**功能缺失的肿瘤抑制蛋白无法直接给药激活 → 必须绕路**（这本身就是 Innovation 叙事）。按评审权重分配精力：

| 评审标准 | 权重 | 我们的对策 |
|---|---|---|
| Scientific Rigor | 35% | 每条结论 EV 编号可溯源 + 主动列反面证据 + 代码可复现 |
| Potential Impact | 25% | 落到患儿现实获益（癌症预防/监测优化）+ 给出 MVA Society 线虫体系可检验的预测 |
| Innovation | 25% | LOF 绕路框架 + LINCS L1000 签名反转 + 多角度组合 |
| Scalability | 15% | 抽象成「N-of-1 罕见病重定位工作流」——管线即产品 |

**副线 · T1（快速满分）**：Exomiser 基线 + comp-het 过滤链 + 本地评分器（官方逻辑复刻）先验证再提交；每人 6 次配额当"神谕"反馈用，尽早试水。满分后重仓 methods 报告（ACMG 分级、反式证据、HPO 匹配、secondary findings 临床建议）。

**第三路径 · 🌟创新奖**：患者为中心交付物——家庭版"结果解释器"（把 comp-het 诊断和药物假设翻译成家长能懂的话）、MVA 监测日历工具。独立于名次评奖，素材与 T2 报告复用。
