# 00 · 项目架构与工作流

> 状态：架子与工作流框架（用户要求先搭骨架，不写业务代码）。各阶段实现细节随后逐步填充。

## 1. 设计原则

1. **合规优先**：原始数据永不入 git（.gitignore 拦截 data/raw、data/processed）；数据永不发给 Recipient 型服务（LLM 按 Processor 配置，见 01-赛制摸底 §5）
2. **可复现**：每步产物落盘 + 参数/版本记录；环境锁定（Python 3.13 + requirements.txt）
3. **提交配额是稀缺资源**：本地复刻官方 evaluation.py 做评分 harness，先本地验证格式与排名，再消耗线上配额（T1×6 / T2×3 且只看最新）
4. **GRCh38 明确假设**（官方讨论 #17 确认），不做参考基因组无关化
5. **文档即产品**：T1 methods 报告与 T2 报告/视频是评审主对象，代码仓库为支撑证据

## 3. Track 1 工作流（8 阶段）

| # | 阶段 | 输入 → 输出 | 工具基线 | 完成标准 |
|---|---|---|---|---|
| S0 | 数据获取与合规登记 | gated dataset → data/raw | `hf download` | 文件清单+校验和入库；LLM 使用日志建档 |
| S1 | QC 与数据熟悉 | raw VCF → QC 报告 | bcftools、FastQC 思路 | 样本=PROBAND01 确认、覆盖度/性别核查、HPO 表型词条整理 |
| S2 | 变异注释 | VCF → 注释表 | VEP/ANNOVAR + gnomAD + ClinVar + CADD/REVEL/AlphaMissense + SpliceAI | 注释字段齐备、可增量重跑 |
| S3 | 候选过滤 | 注释表 → 稀有候选集 | AF<阈值（gnomAD/TOPMed）、质量过滤、LOF+missense | 候选数降到人工可审规模 |
| S4 | 表型整合 | 候选 × HPO → 优先级 | Exomiser/LIRICAL | 基因-表型相似度评分入表 |
| S5 | comp-het 相位分级 | 候选 → 相位证据等级 | read-backed/trio/长读；不可用时保留架构推断 | 输出 direct / parental-supported / architecture-inferred / unresolved；本例短读无法跨越 >10 kb，当前为 architecture-inferred |
| S6 | 排名与提交打包 | 优先级表 → 提交 CSV | **本地评分 harness（复刻 evaluation.py）** | 本地格式/排名校验通过 → 消耗线上配额 |
| S7 | 方法学写作 | 全程记录 → 报告 | 官方模板 + LLM 披露行 | 覆盖评审要素清单（见 04-机会点 §2） |

**已知答案结构约束**（源码确认）：comp-het 双变异对 → S3/S5 是核心；提交 CSV 中 comp-het 对必须同行。

## 4. Track 2 工作流（5 阶段）

| # | 阶段 | 输入 → 输出 | 完成标准 |
|---|---|---|---|
| M1 | 机制刻画 | T1 结果 + 文献 → 机制链条文档（变异→LOF→SAC→非整倍体→表型/癌易感） | 报告主轴成立，每个环节有引文 |
| M2 | 靶点假设 | 机制链 → 可绕路靶点清单（SAC 补偿/非整倍体清除/CIN 应激/化学预防/对症） | 每个靶点写明"为什么绕得过 LOF" |
| M3 | 药物挖掘 | 靶点 × 数据库（Open Targets/DGIdb/DrugBank/LINCS/Repurposing Hub/CTD）→ 候选药物长表 | 仅**已上市药物**；含作用机制与证据源 |
| M4 | 证据分级 | 长表 → 精选清单（证据强度 × 影响 × 可行性矩阵） | 每候选可追溯到原始证据；给出线虫可检验预测 |
| M5 | 报告与视频 | 精选清单 → 报告 + 3 分钟 pitch | 对照四项评审标准逐项自检 |

## 5. 横切关注点

- **本地评分 harness**：逻辑照抄公开的官方 `evaluation.py`（rank tiers / comp-het 半分 / F-max 扫描 / CSV 校验），放 `src/track1_variant/`——提交前必跑
- **证据台账**：`research/evidence.jsonl`——所有关键 claim 结构化入账（schema 见 `research/README.md`），终版报告只准引用台账内 EV 编号（Reporter 隔离）；台账同时是 T2 证据分级表的机器可读版
- **LLM 使用日志**：`docs/llm-usage.log` 记录 provider/tier/setting，供 methods 披露行直接引用
- **数据删除清单**：赛末 30 天内执行（范围见 01-赛制摸底 §6），确认邮件模板备好
- **提交台账**：`submissions/` 每次提交留档（时间、配额消耗、官方反馈、分数），避免记错配额
- **GitHub 公开**：评审开始前切换 public；公开前跑一遍"无基因组级数据"自检
