# 03 · 疾病背景 | MVA 与 BUB1B——T2 弹药库

> 本章是 Track 2 的机制与文献基础。事实均有多源交叉验证，来源见文末。

## 1. MVA 综合征是什么

- **Mosaic Variegated Aneuploidy（镶嵌性斑驳非整倍体）**：超罕见常染色体**隐性**遗传病（本赛案例口径：全球在世的 <50 人）
- 各组织呈镶嵌样广泛非整倍体（三体/单体并存），根源是有丝分裂染色体分离错误
- 核心表型：宫内/产后生长迟缓、小头畸形、发育迟缓/智力障碍；部分合并免疫缺陷、先心病、Dandy-Walker 畸形等
- **癌症易感是最大死因风险**：BUB1B 突变者癌症发生率 ~75%（Wilms 瘤、横纹肌肉瘤、白血病为主）；CEP57 型暂无癌症报告
- 现状：**无任何疾病修饰疗法**；管理 = 对症支持 + 肿瘤监测（英国方案：定期肾脏超声筛查 Wilms 瘤等）

## 2. 基因分型（含用户提示的核实结果）

| 亚型 | 基因 | OMIM | 编码蛋白 / 功能 |
|---|---|---|---|
| **MVA 1 型** | **BUB1B** | 257300 | BUBR1：纺锤体组装检查点（SAC）核心激酶 |
| **MVA 2 型** | **CEP57** | 614114 | 中心体蛋白，微管成核 |
| MVA 3 型 | TRIP13 | — | p31(comet)/MAD2 通路，SAC 关闭 |

**用户提示"查 BUB1B 和 MVA 2 型的关系"——答案：BUB1B 对应 MVA 1 型，不是 2 型**；MVA 2 型是 CEP57。多个来源（MVA Society、OMIM 257300、Orphanet）一致。

**综合判断**：evaluation.py 证实答案是 comp-het 双变异（隐性）→ 与 MVA 的常隐遗传吻合 → 头号嫌疑 **BUB1B 复合杂合（MVA1，MalaCards 明确 MVA1 由 BUB1B 纯合或 comp-het 突变导致）**。BUB1B 位于 15 号染色体（15q15.1），数据到手后第一时间核查该区域（具体坐标用 region 查询确认）。次要嫌疑：CEP57（chr11）、TRIP13（chr5）。

*巧合级信号（不作依据）*：官方 groundtruth.py 的本地开发用假答案恰好是 chr2 + chr15 两个变异的组合——BUB1B 在 chr15，其旁系同源基因 BUB1 在 chr2。代码注释明确说坐标是假的，仅记录备查。

## 3. BUB1B / BUBR1 生物学（T2 机制叙事的主轴）

- BUBR1 是纺锤体组装检查点（SAC）核心：与 BUB3/MAD1/MAD2/CDC20 组成有丝分裂检查点复合物（MCC），**抑制 APC/C**，阻止动粒未附着的细胞进入后期
- 兼职校正动粒-微管（K-MT）附着的稳定性
- 经典肿瘤抑制基因：双等位 LOF → 检查点失效 → 非整倍体风暴 → MVA1；残余蛋白量与表型严重度相关（eLife 2016：不同 BUBR1 变异对非整倍体/癌症的抵抗力有差异）
- **成药性核心难题：BUBR1 是 LOF——丢失功能的肿瘤抑制蛋白无法直接"给药激活"** → T2 必须绕路（这正是创新点所在，见 04-机会点）

## 4. 现有管理 & 研究方向（T2 弹药库）

**在研方向（可与我们的方案衔接）**：
- **MVA Society 正资助线虫（C. elegans）高通量表型分析 + 药物筛选** → 我们的候选药物若能给出线虫可检验的预测，即与主办方自己的验证体系接轨（可验证性 = Scientific Rigor 加分项）

**可挖掘的通路角度**（LOF 绕路思路）：
1. **SAC 残余功能补偿**：增强残余检查点活性或平行通路冗余（MAD2、BUB1、TTK/MPS1、AURKB、PLK1——注意多数是肿瘤药物的抑制靶点，需反转思维：别构调节 / 低剂量窗口 / 组织特异性）
2. **非整倍体细胞清除**：促凋亡偏向——让应激的非整倍体细胞更易被清除（而非任其累积）
3. **CIN 应激通路**：非整倍体引发的炎症/应激（JNK、p38、cGAS-STING）——缓解"非整倍体毒性"而非纠正非整倍体本身
4. **癌症化学预防**：CIN 模型中 NSAIDs 等药物的防癌证据——针对 ~75% 癌症发生率这一最致命风险
5. **症状层重定位**：免疫缺陷、GI 症状等具体表型的对症已上市药物

**数据库弹药**：Open Targets、DGIdb、DrugBank、ChEMBL、LINCS L1000（签名反转）、Broad Repurposing Hub、CTD

**合规边界**：只能提名**已上市药物**；实验性化合物不行（讨论 #5 旁证）。
